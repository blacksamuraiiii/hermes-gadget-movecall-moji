## 一条线读懂现状

墨迹板是 **Hermes Agent 的消息提醒屏 + 语音入口**：USB 线直连（不经 Wi-Fi），屏上只有小墨的纯表情（20 态、无文字、无触摸），唤醒词「小墨小墨」在板上跑 MultiNet5；三类人工介入（授权 / 选择 / 完成）走插件内通知桥。固件基线是上游 v0.6.0 加上本 fork 的纯表情线。

## 关键速记（动手前必看）

- **本板不在上游支持表**，port 已由本 fork 完成（v0.1）；同为 240 圆屏的 Spotpear 1.28-BOX 驱动与引脚都不同，不可照抄 profile。
- **采样率 24 kHz 是板级常量**，照抄 16 kHz 会变调变速；唤醒引擎在 24k→16k 换采样由 `esp_ae_rate_cvt` 做。
- **屏是 SPI 40 MHz，不是 I2C**；排线长会花屏，改线先降 20 MHz 验证。
- **USB 链路下没有 Wi-Fi 配网**：要回 Wi-Fi 需注释 `CONFIG_HG_LINK_USB_SERIAL` 重编，代码不用改。
- **刷写与 console 只能开 COM5**：relay 独占该口，先停 relay；`tools/console_cmd.py` 会自动让路再恢复。第一次上 0.6 必须全量刷五段（`app-flash` 与 OTA 不写 `model`）。
- **纯表情板不宣告需文字的能力**：`send_hello` 里 `text_ui = ui_ && !profile_.emoji_face`，卡片/选项/仪表盘/profile/口译/`caps.faces` 全被它挡住。
- **插件有两份副本**：gateway 加载 `~/hermes-sync/plugins/gadget/`，改项目 `plugin/` 后必须同步并 `diff -rq` 确认。
- **上游吸收后要逐项回植本地资产**：天气工具（`gadget_weather`）、提醒桥（`BRIDGE.register`）、唤醒词、USB 链路、纯表情渲染，本 fork 独有；漏一个就表现为「功能静默消失」（天气改网搜、完成提示不响）。
- **`hermes gadget update --latest` 指向上游 release**（`plugin/releases.py` 写死仓库地址），认不到 fork 自己的包。

## 命名与收录约定

- 文件名 `类别-主题.md`。类别：硬件 / 路线 / 决策 / 验收 / 环境 / 待办 / 设计 / 上游。待办带日期与版本号。
- **一类信息只放一处**：决策进台账，实测进验收，坑与环境事实进环境，一次性计划与审查完成后进 `归档/`。
- 每份文件开头三行内写清「用途 / 核对日期 / 取代关系」。
- 一律中文；命令、路径、日志原文不改写，`[码]/[测]/[推]/[?]` 证据标记沿用。
- 上游 `docs/` 里的文档引用不要改；本项目自己的引用随文件改名同步。
